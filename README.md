# 出張買取ハピフル 公式ホームページ制作案

スマホ対応の1ページ静的サイトです。ビルド・外部ライブラリ・外部フォント・サーバー処理は不要です。**まだ一般公開しないでください。** GitHub Pages設定や自動デプロイのワークフローは追加していません。

## プレビュー

1. このブランチを Code → Download ZIP でダウンロードして展開します。
2. `index.html` をブラウザで開きます。スマホ相当の幅はブラウザの開発者ツールで確認できます。
3. 任意で Python があれば、展開したフォルダで `python3 -m http.server 8000` を実行し、同じ端末の `http://localhost:8000` を開きます。

外部公開のプレビューサービスを使う必要はありません。LINEボタンはすべて実際の公式LINEへ移動します。

## マスコット画像の設置・差し替え

アップロード画像をもとに画像編集ツールで背景透過したWebP（約122KB）を `assets/mascot.webp` に設置済みです。生成編集のため元画像と細部が異なる可能性があります。厳密な原画を使う場合も、以下の方法で差し替えられます。

1. 確認用ブランチ `preview/hapifuru-website` を選びます。
2. ハートを持ったフクロウの正式画像を `mascot.webp` という名前で `assets/` フォルダへ追加します（GitHubでは Add file → Upload files）。設置先は **`assets/mascot.webp`** です。
3. このブランチに保存して、最新版をダウンロード・展開し `index.html` を開き直します。画像が読み込めると仮置き部分が自動で画像に切り替わります。HTMLの編集は不要です。
4. 画像を更新するときは同じファイル名で差し替え、必要ならブラウザを強制再読み込みします。Pagesは有効にしないでください。

PNGを使う場合は `assets/mascot.png` に置き、`index.html` の `class="mascot-image"` の `src="assets/mascot.webp"` を `src="assets/mascot.png"` に変更してください。拡張子だけの変更では画像形式は変わりません。大文字・小文字も一致させてください。

透過背景、幅600〜800px程度、200KB以下が目安です。画像の周囲の余白は少なくするとフクロウが大きく見えます。CSSの `object-fit: contain` により縦横比を保ち、画像全体を表示します。スマホでは表示枠を従来の幅240px・高さ250pxから、最大幅350px・高さ350pxに拡大しています。

画像未設置・読込失敗時は既存の仮置きを表示します。未設置の間は開発者ツールに画像の404が出る場合があります。JavaScript無効時も仮置き表示を維持します。

## 確認後のGitHub Pages公開手順（未実施）

1. すべての必須確認を終え、公開を決定した時点で変更を `main` に反映します。
2. `index.html` の `noindex,nofollow` を `index,follow` に変更します。検索避けタグはアクセス制限ではありません。
3. 正式な公開URLでcanonical、OGP URL/画像、sitemap.xmlを用意します。未確定URLや住所をSEO用データとして作らないでください。
4. GitHubリポジトリの Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。
5. 公開後にHTTPS・表示・LINEリンクを再確認。必要に応じSearch Consoleに登録します。

相対パスで構成しているため `/hapifuru-website/` 配下でも動作します。`.nojekyll` を同梱しています。構造化データは事業者情報の確認後に実態に合うものを追加してください。公開前の現在は意図的に検索インデックスを避けています。
